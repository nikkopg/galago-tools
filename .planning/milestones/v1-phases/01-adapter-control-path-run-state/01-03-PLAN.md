<objective>
The F.A.S.T. reports live run state on the health `GetStatus` RPC that galago-core already polls:
`StatusReply.run_state` (D-09) with the state, the percent and the current pause (D-11), taken from
the adapter's own record while a run is in flight and from a fresh `service.status()` otherwise
(D-12), never commanding the instrument (D-14), and never failing the heartbeat.

Purpose: galago-core's run page needs to see "running at 42%" or "paused: WrongPlateType, deck 3"
to open its prompt; without run_state the operator cannot see what the instrument is doing.
Output: the `run_state` proto field, the run record (`_run_in_flight`, `_log_progress`,
`_record_pause`), the builder (`_build_run_state`) and the `GetStatus` fill-in, with tests.
</objective>
