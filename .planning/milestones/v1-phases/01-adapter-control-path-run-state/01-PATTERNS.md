### `interfaces/tools/grpc_interfaces/fast.proto`

**Analog:** same file, existing `Abort`/`Resume` oneof members (lines ~8-9, 54-61)

**Core pattern** (verbatim, to copy the shape from):
```protobuf
message Command {
  oneof command {
    ...
    Abort abort = 8;
    Resume resume = 9;
    // NEW: Pause pause = 10;
  }

  // Operator recovery from an instrument pause. The physical decision is a
  // required "yes"/"no" string, not a bool: galago-core's command form turns
  // an untouched boolean into false, so a bool could not tell "no" from
  // "never chosen". Unset or any other value is rejected as INVALID_ARGUMENTS.
  message Abort {
    optional string return_liquid = 1;
  }

  message Resume {
    optional string is_tip_broken = 1;

}
```
D-05 note: unlike `Abort`/`Resume`, `Pause {}` takes **no fields** — no decision string needed,
so `_check_args`'s `name in _RECOVERY_DECISION_FIELD` branch does not apply to it and should fall
through to the final `return []`.

### `tools/fast/server.py` — `ExecuteCommand` override (controller, request-response)

**Analog 1 — the override idiom to copy, `GetStatus` dual-dispatch** (`server.py:450-468`, existing,
unmodified):
```python
def GetStatus(self, *args: object) -> object:  # type: ignore[override]
    """Dual-purpose, by necessity: ... Arity is therefore a safe, stable discriminator."""
    if len(args) == 2:
        return super().GetStatus(*args)  # type: ignore[arg-type]
    (params,) = args
    return self._get_status(params)  # type: ignore[arg-type]
```
`ExecuteCommand` follows the identical "override, discriminate, else call `super()`" shape, but
discriminates on `WhichOneof` instead of arity.

**Analog 2 — the exact gate being bypassed, `base_server.py` `ExecuteCommand`/`parseCommand`**
(`tools/base_server.py:195-256`, READ-ONLY, never edit):
```python
def isReady(self) -> bool:
    if self.simulated:
        return True
    return self.status == tool_base_pb2.READY

def parseCommand(self, request):
    if not self.isReady():
        return None, tool_base_pb2.NOT_READY, None
    ...

def ExecuteCommand(self, request, context):
    command, error, error_msg = self.parseCommand(request)
    if error is not None:
        self.last_error = error_msg
        return tool_base_pb2.ExecuteCommandReply(response=error, error_message=error_msg)
    if command is not None:
        try:
            logging.debug("Setting tool to BUSY")
            self.setStatus(tool_base_pb2.BUSY)
            logging.info(f"Running command {command.__class__.__name__}")
            response = self._dispatchCommand(command)
            ...
            return response
        except Exception as e:
            self.last_error = str(e)
            return tool_base_pb2.ExecuteCommandReply(
                response=tool_base_pb2.DRIVER_ERROR, error_message=str(e))
        finally:
            self.setStatus(tool_base_pb2.READY)
    return tool_base_pb2.ExecuteCommandReply(response=tool_base_pb2.SUCCESS)
```
Note the exact logging strings to mirror (D-02): `logging.info(f"Running command {command.__class__.__name__}")`,
and the `except Exception as e: self.last_error = str(e)` / `DRIVER_ERROR` shape.

**Error handling pattern to copy (`DRIVER_ERROR` + `last_error`):** same `try/except Exception as e`
block shown above — the override must replicate this exactly for the control-command branch, since
it bypasses `base_server.ExecuteCommand` entirely (never calls `setStatus`, never calls `isReady`).

**Illustrative sketch already drafted in RESEARCH.md (Pattern 2, grounded, not yet written):**

```python
CONTROL_COMMANDS = frozenset({"pause", "resume", "abort"})  # fast.Command oneof field names (lowercase)

        field_name = fast_command.WhichOneof("command")

                return tool_base_pb2.ExecuteCommandReply(
                    response=tool_base_pb2.DRIVER_ERROR, error_message=str(e))
    return super().ExecuteCommand(request, context)
```
Dispatches through `self._dispatchCommand(command)` (the already-overridden one at `server.py:342`,

### `tools/fast/server.py` — `Pause()` method (controller, request-response)

**Analog:** `Abort()` (`server.py:386-409`), minus the decision-field check since `Pause {}` has none:
```python
def Abort(self, params: "Command.Abort") -> ExecuteCommandReply:
    """Operator-issued abort of a running or paused run. ..."""
    return_liquid = _decision(params, "return_liquid")
    if return_liquid is None:
        return _reply(INVALID_ARGUMENTS, message="return_liquid must be 'yes' or 'no'")
    service = self.service
    if service is None:
        return _reply(NOT_READY, message=_NOT_CONNECTED_MESSAGE)
    if not self._motion_lock.acquire(blocking=False):
        return _reply(NOT_READY, message=_BUSY_MESSAGE)
    try:
        try:
            result = service.abort(return_liquid=return_liquid)
        except (InstrumentHTTPError, httpx.HTTPError) as exc:
            return _transport_error_reply(exc)
        return _recovery_reply("abort", result)
    finally:
        self._motion_lock.release()
```
**Pause() must drop the `_motion_lock` acquire/release entirely** (D-06: Pause/Abort never touch
`_motion_lock` — wait, D-06 actually says Pause and Abort never touch it; re-check: **D-06 says Pause
and Abort never touch `_motion_lock`** — so `Abort`'s lock usage above is itself changing in this
phase; see "Shared Patterns" below). The resulting `Pause()` shape (no lock, no decision field):
```python
def Pause(self, params: "Command.Pause") -> ExecuteCommandReply:
    service = self.service
    if service is None:
        return _reply(NOT_READY, message=_NOT_CONNECTED_MESSAGE)
    try:
        result = service.pause(hard=False)
    except (InstrumentHTTPError, httpx.HTTPError) as exc:
        return _transport_error_reply(exc)
    return _recovery_reply("pause", result)
```

reused as-is for Pause):

```python
def _recovery_reply(action: str, result: "dict | Refused") -> ExecuteCommandReply:
    """Map FastService.abort/resume's `dict | Refused`. ..."""
```

### `tools/fast/server.py` — `Resume()` lock-split rewrite (controller, request-response)

**Analog:** existing `Resume()` (`server.py:543-578`, to be replaced) — read in full above. The
non-blocking-acquire two-branch sketch is already drafted in RESEARCH.md Pattern 3 (grounded,
illustrative):
```python
def Resume(self, params):
    is_tip_broken = _decision(params, "is_tip_broken")
    if is_tip_broken is None:
        return _reply(INVALID_ARGUMENTS, message="is_tip_broken must be 'yes' or 'no'")
    service = self.service
    if service is None:
        return _reply(NOT_READY, message=_NOT_CONNECTED_MESSAGE)
    if self._motion_lock.acquire(blocking=False):
        # Crash-recovery path: no motion command in flight. Unchanged behavior.
        try:
            try:
                accepted = service.resume(is_tip_broken=is_tip_broken)
                if isinstance(accepted, Refused) or accepted.get("errorCode") != 0:
                    return _recovery_reply("resume", accepted)
                result = service.wait(
                    RunHandle(plates=None, stale_done=False),
                    on_progress=self._log_progress, timeout_s=self._timeout(None))
            except (InstrumentHTTPError, httpx.HTTPError) as exc:
                return _transport_error_reply(exc)
            return _result_reply(result)
        finally:
            self._motion_lock.release()
    # In-flight path: a motion command holds the lock. No wait, no lock interaction.
    try:
        accepted = service.resume(is_tip_broken=is_tip_broken)
    except (InstrumentHTTPError, httpx.HTTPError) as exc:
        return _transport_error_reply(exc)
    return _recovery_reply("resume", accepted)
```
**Anti-pattern flagged in RESEARCH.md** (do not copy): the acquire-or-NOT_READY idiom used by
`Transfer`/`RunProtocol`/`ScanTips`/`EjectTray` (`server.py:353-357` etc.) is structurally wrong
here — there is no "busy" branch for Resume anymore, only "wait" vs "no-wait".

**Analog 3 — blocked-thread technique**, `TestMotionSerialization.test_second_motion_command_refused_while_first_in_flight`
(`fast_test.py:545-608`):
```python
release = threading.Event()
entered = threading.Event()

def _blocking_run_transfer(*args, **kwargs):
    entered.set()
    release.wait(timeout=5)
    return Ran(outcome=RunOutcome(state="idle", done=True, percent=100))

self.service.run_transfer.side_effect = _blocking_run_transfer
...
thread_a = threading.Thread(target=self.server.Transfer, args=(...,))
thread_a.start()
self.assertTrue(entered.wait(timeout=5))

    reply = self.server.Transfer(...)
    self.assertEqual(reply.response, NOT_READY)
    ...

```
**Critical adaptation for ADP-08 (RESEARCH.md Pitfall 6):** this existing test drives `Transfer`/
`Abort`/`Resume` as **direct Python calls on `self.server`**, which never exercises
`base_server.ExecuteCommand`'s gate at all. The new test must drive **both** the blocked Transfer
**and** the concurrent Pause/Resume/Abort through `self.stub.ExecuteCommand(...)` (the real
in-process gRPC stub from Analog 1), not `self.server.Transfer(...)` directly — otherwise the test
passes trivially without proving the override bypasses the gate.

**Composed test shape (new, illustrative):**
```python
class TestControlCommandsDuringTransfer(_MockedFastServerTestCase):
    def setUp(self):
        super().setUp()
        self._grpc_port = _free_tcp_port()
        self._server = grpc.server(futures.ThreadPoolExecutor(max_workers=4))
        add_ToolDriverServicer_to_server(self.server, self._server)
        self._server.add_insecure_port(f"127.0.0.1:{self._grpc_port}")
        self._server.start()
        self.addCleanup(self._server.stop, None)
        self._channel = grpc.insecure_channel(f"127.0.0.1:{self._grpc_port}")
        self.addCleanup(self._channel.close)
        self.stub = ToolDriverStub(self._channel)

    def test_pause_resume_abort_reach_service_while_transfer_in_flight(self):
        release = threading.Event()
        entered = threading.Event()
        def _blocking(*a, **kw):
            entered.set(); release.wait(timeout=5)
            return Ran(outcome=RunOutcome(state="idle", done=True, percent=100))
        self.service.run_transfer.side_effect = _blocking

        thread = threading.Thread(
            target=self.stub.ExecuteCommand,
            args=(tool_base_pb2.Command(fast=fast_pb2.Command(
                transfer=fast_pb2.Command.Transfer(**_ALL_TRANSFER_FIELDS))),))
        thread.start()
        self.assertTrue(entered.wait(timeout=5))

        for name, cmd in (("pause", fast_pb2.Command.Pause()),
                           ("resume", fast_pb2.Command.Resume(is_tip_broken="no")),
                           ("abort", fast_pb2.Command.Abort(return_liquid="no"))):
            reply = self.stub.ExecuteCommand(tool_base_pb2.Command(
                fast=fast_pb2.Command(**{name: cmd})))
            # each reaches the mock exactly once; status stays BUSY (GetStatus health RPC)
            status = self.stub.GetStatus(tool_base_pb2.Config())
            self.assertEqual(status.status, tool_base_pb2.BUSY)

        release.set()
        thread.join(timeout=5)
        # Transfer ends SUCCESS, status returns to READY
```
Note: `tearDown`'s `assert_not_called()` checks from `_MockedFastServerTestCase` must be overridden
or removed for this specific test class, since it deliberately calls pause/resume/abort.

## Potential Naming Collision (flag for planner, not a pattern to copy)

`tools/fast/server.py` already imports `from fast_mcp.model import Protocol` (line 30) for CSV
protocol parsing. D-13's duck-typed recorder interface needs `typing.Protocol` for a
`Protocol`-based structural type. **These two names collide.** The executor must alias one on
import, e.g. `from typing import Protocol as _ToDictableProtocol` or `import typing as t` then
`t.Protocol`, mirroring `base_server.py`'s own `import typing as t` convention
(`tools/base_server.py:3`) — recommend following `base_server.py`'s `import typing as t` idiom and
referencing `t.Protocol` in `server.py` to avoid the collision entirely.
