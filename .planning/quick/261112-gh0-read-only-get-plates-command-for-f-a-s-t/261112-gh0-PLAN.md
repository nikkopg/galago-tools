<objective>
Add a read-only `get_plates` command to the F.A.S.T. Galago tool. It lists the plate definitions
registered on the instrument through fast-mcp's `FastService.plate_definitions`. It never takes the
motion lock, never checks whether the instrument is idle, and answers while a Transfer is running.
To do that it bypasses base_server's READY/BUSY gate the same way the STACK adapter's
`READ_COMMANDS` set does.

Purpose: an operator (or galago-core) can read which plate ids exist on the instrument at any
time, including mid-transfer, without disturbing the run.
Output: an additive fast.proto change (regenerated, gitignored Python stubs), the FastServer
`GetPlates` handler plus the `READ_COMMANDS` bypass, and tests that prove the bypass through the
real gRPC `ExecuteCommand` path.
</objective>
