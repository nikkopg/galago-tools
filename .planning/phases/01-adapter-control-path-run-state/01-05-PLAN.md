<objective>

an instrument (D-18), run_state reports running during a simulated run and idle otherwise (D-19),
and an in-process test hook drives run_state to paused with a PauseInfo-shaped detail (D-20), so
galago-core's pause prompt and controls can be exercised without hardware (ADP-10).

Purpose: galago-core's companion milestone builds the run-page prompt against this adapter. Without a
simulated pause it could only be tested on the instrument.

`_build_run_state`, the simulated run marker in `_dispatchCommand`, and their tests.
