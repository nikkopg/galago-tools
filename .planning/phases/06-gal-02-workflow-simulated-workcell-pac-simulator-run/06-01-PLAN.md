1. Protocol script (per D-03, D-05, D-13, D-14).
   Write the script text in a session scratch file, never in the repo. Follow RESEARCH Pattern 1
   (06-RESEARCH.md lines 254-316), with these points fixed.

   Style and helpers:
   - Use `var` and function declarations only.
   - Define the helpers `text(name)`, `need(name)`, `whole(name)` and `positive(name)`:
     - `text` treats undefined, null and blank as an empty string and trims;
     - `need` throws `new Error("GAL-02: parameter '" + name + "' is required")`;
     - `whole` throws "... must be a whole number";
     - `positive` throws "... must be a number above 0".

   Key base:
   - `label` is `Array.from(need("batch_label")).slice(0, 20).join("")`. This cuts by code point, so
     no lone surrogate is possible (FLOW-04 encoding edge).
   - `rand` is `(Math.random().toString(16) + "00000000").slice(2, 10)` (Pitfall 11).
   - `base` is `label + "-" + new Date().toISOString() + "-" + rand`.
   - The keys are `base + "-in"` and `base + "-out"` (D-05).

   STACK legs:
   - `stackLeg(suffix, from, to)` builds `step_key`, `robot` and `labware_profile`. It then builds
     `source_device`, `source_deck` and `source_nest` from `from + "_device"` (and so on), and the
     `destination_*` fields from `to + "_*"`.
   - The `from`/`to` transfer profile maps to `source_transfer_profile` /
     `destination_transfer_profile`, set only when non-blank.
   - `timeout_s` is `positive("stack_timeout_s")`, set only when that parameter is non-blank.
   - `legIn` is `stackLeg("-in", "source", "fast")`. `legOut` is `stackLeg("-out", "fast", "source")`,
     the swap (D-04).

   F.A.S.T. step:
   - `fastStep()` maps each `fast_step_<field>` parameter onto the fast.proto field `<field>` (D-13):
     - `whole` for source_deck, dest_deck, source_plate_id, dest_plate_id, source_start_col,
       dest_start_col, num_rows and num_cols;
     - `need` for source_start_row, dest_start_row and tip_reuse;
     - `positive` for volume;
     - `expected_tray_id` via `whole`, only when non-blank.

   Emit order:
   - Read `stackTool = need("stack_tool")` and `fastTool = need("fast_tool")`.
   - Build legIn, fastParams and legOut BEFORE any galago call, so a bad input throws with zero
     commands emitted.
   - Then call `galago.note("GAL-02 key base " + base)`, `galago.command(stackTool, "transfer", legIn)`,
     `galago.command(fastTool, "transfer", fastParams)` and `galago.command(stackTool, "transfer", legOut)`.
   - Emit nothing else.

   D-03 note, record it in the SUMMARY: D-03 says `Number()` converts numerics. Its
   `Number(params.x) || default` idiom has no applicable field here:
   - every required numeric has its default in `parameters[].defaultValue`, shown in the run form,
     and a blank throws (D-04);
   - every optional numeric falls back to the adapter default by being omitted (D-14).
   No script-side fallback exists, so a blank can never silently become a sim value.
