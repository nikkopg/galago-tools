<objective>
Prove LIVE-03 on the real core: time spent paused does not count toward the run timeout, and a
timeout still never aborts.

The core already excludes live-paused time from the deadline at poll granularity (`poll_run`, S6);
the adapter's only job is passing `through_pauses=True`, done in plan 02-01, and it must add no
clock of its own (D-12). This plan proves it with the real core on an injected clock (D-13): a
pause far longer than the timeout ends SUCCESS, the same time spent running ends TimedOut with no
control call (D-16's timeout case), and the exact threshold and pause granularity are pinned (the
LIVE-03 boundary and precision edges). RunProtocol's per-command timeout gets the same proof, and
pause episodes record once each.

Purpose: ROADMAP Phase 2 success criteria 3 (second half) and 4.
Output: `_no_sleep`, `_fake_clock` and `TestPausedTimeExcludedFromTimeout`. Test-only: server.py is
not modified.
</objective>
